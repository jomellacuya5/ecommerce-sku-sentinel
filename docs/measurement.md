## Calculation

```text
hours_saved_per_month = (manual_monthly_minutes - automated_monthly_minutes) / 60
```

Example only: a 15-minute daily manual check on 22 working days is 330 minutes/month. If the automated exception review takes 5 minutes on 22 days, the measured saving is 220 minutes, or 3.7 hours/month.

Record the source period, the number of scheduled runs, successful runs, failed runs, and whether failure alerts were received.
